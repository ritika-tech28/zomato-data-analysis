
# Zomato Data Analysis Project

## 📌 Overview

This project analyzes Zomato restaurant data using **Python** to understand customer preferences, restaurant trends, ratings distribution, and online ordering behavior.
The analysis is performed using data visualization and statistical techniques to extract meaningful business insights.

---

## 🛠️ Tools & Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

---

## 📊 Analysis Performed

### 1. Data Cleaning

* Converted restaurant ratings from text format to numeric format.
* Handled missing and inconsistent values.

### 2. Restaurant Type Analysis

* Most restaurants belong to the **Dining** category.

### 3. Votes Analysis

* Dining restaurants received the highest number of votes from customers.

### 4. Ratings Analysis

* Most restaurant ratings fall between **3.5 and 4.0**.

### 5. Cost Analysis

* Most couples prefer restaurants costing around **₹300 for two people**.

### 6. Online vs Offline Orders

* Restaurants offering online ordering received better customer ratings.

### 7. Heatmap Analysis

* Dining restaurants mostly receive **offline orders**.
* Cafes mostly receive **online orders**.

---

## 🔍 Key Insights

* Dining restaurants are the most popular among customers.
* Online ordering positively impacts customer ratings.
* Customers prefer mid-range restaurants over expensive ones.

---

## 📈 Conclusion

This project helps in understanding:

* Customer behavior
* Restaurant trends
* Ordering preferences

using **data analysis** and **visualization techniques**.
